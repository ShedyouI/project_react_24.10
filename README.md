# Каталог компьютерной техники

Учебное полнофункциональное веб-приложение: frontend, backend и база данных.

Ссылка на Git-репозиторий:  
https://github.com/YOUR_GITHUB_USERNAME/catalog-app

## Технологии

- Frontend: React + Vite
- Backend: Node.js + Express
- База данных: PostgreSQL 16
- Контейнеризация: Docker + Docker Compose
- Формат обмена данными: JSON

## Возможности

- Отображение каталога товаров в виде карточек.
- Карточка товара содержит:
  - название;
  - описание;
  - изображение;
  - цену.
- Добавление товара через API.
- Удаление товара через API.
- Поиск по названию и описанию.
- Фильтрация по категории.
- Фильтрация по диапазону цен.
- Сортировка по дате, цене и названию.
- Отдельная страница товара.
- Все данные берутся из PostgreSQL через backend API.
- Товар можно добавить напрямую в базу данных и увидеть на сайте после обновления страницы.
